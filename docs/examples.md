# Examples

## OP Sepolia Vite App

A minimal Vite + React + TS app that deposits ETH to OP Sepolia via L1 Sepolia using this SDK.

Path: `examples/op-sepolia-vite/`

Run:

```bash
bun install && bun run build # at repo root
cd examples/op-sepolia-vite
bun install
bun run dev
```

Open `http://localhost:5173` and fill out the form. Use a test private key.
